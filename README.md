# My Personal Website

This is the repository for [My Website](https://droppedspoon.net).
I set out to create this website as an unemployed college graduate to gains some skills and have a bit more on my resume. The project has turned into one of my favorite creative endeavors and I hope to add it to neocities when it's ready.
When you visit the site, I hope you will be able to feel the passion that went into it, and enjoy your time there.

## Pages

The following is a list and breakdown of the pages you can find on my site:

### **Home**

I really like my home page. It was not the easiest forray into the world of React to create navigation buttons the float around the screen randomly while also making sure the buttons did not lose any accessibility in doing so, but I like where I landed. I'm still really proud of my hot air balloon navigation system.
Desktop users will notice the paralaxing background images, I was really proud when I got that working too. Nowadays... it causes some headaches in positioning new elements against the background like the truck I added on the ground but I think I have a good compromise for that in place. I made a little road image to go with the truck and stuck them both along the bottom of the viewport and that works well enough for me. I'll probably add other cool ways to navigate in the future, but hot air balloons will likely nav to main pages.

### **Portfolio**

This is probably the most standard page on the site, but the styling makes all the difference for me. Lots of fun fonts on this page. I modeled the background imagery off of the target smash background in smash bros melee and I really like how it looks. It's really cool to me what you can do with a couple divs.
Each of the entries in my portfolio here has a video to accompany it. However, I switched out the iframes that would hold the videos with images so the videos won't load until you click on the thumbnail placeholder. That saves a lot of load time and data which is specifically good for mobile users.


This page will get an update soon to add more to my portfolio like:

### **Mini Games**

Game design is one of my passions and I'm really proud of the collection of mini games I have designed and developed here, playable entirely in the browser. I use the matter.js library for the physics and have a wide variety of games. They're all spoon themed though (more or less).
You navigate the game menu by dropping a spoon in the corresponding bucket, and after many design iterations, I think this page is at a point where it adequately explains that feature to visitors.
The following is the current list of games available to play:
- Cereal Shot
- Descent
- Rescue
- Space O's
- Hot Spoontato
- SpoonSaber Battle
- SpeedClick
- ~Homerun~
- Coming soon: Spoon Balloon


I know. My next task is to add leaderboards.

### **Latest Mic**

You can get to this page from the truck driving back and forth at the bottom of the home page. I don't love to post my standup because each performance is different and alive and once it's on the internet, posted, it's kinda stuck- frozen. So I came up with this.
The latest mic page uses youtube api calls through a firebase function to pull and display only the latest video from my stand up performances playlist. I keep the videos unlisted so they don't show up for subscribers but the latest one can always be found at this page. It's great because it updates automatically, I just need to upload to the playlist when I have a new video.
